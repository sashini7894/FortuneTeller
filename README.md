This project was developed as part of the Mobile Application Development Practical Tutorial 02

Application Purpose: We built a cross-platform mobile application using React Native and Expo named "Fortune Teller".

Core Features & Architecture:
   Configured an Android emulator using Android Studio and ran the app via Expo Go.
   Implemented screen-to-screen navigation using Expo Router (Stack navigation) managing a Welcome screen (index.tsx) and a Fortune Reveal screen (reveal.tsx).
   Utilized core React Native UI components like View, Text, Image, Button, and custom styles via StyleSheet.git
